## Standards

AgentSec's standards and scanner interoperability model lives in:

- [Security Standards and Tooling](../references/standards-and-tools.md)

The project is standards-led and tool-assisted. OWASP, CWE, CIS and NIST define the baseline; scanners such as Burp Suite, SonarQube and Snyk contribute evidence.
